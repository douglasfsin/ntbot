Como usar

  • Abra este arquivo no navegador: docs/blueprint/index.html (file:// ou servidor local).
  • Diagramas Mermaid renderizam via CDN — é necessário conexão com a internet na primeira carga.
  • Servidor local opcional (PowerShell): 
    cd c:\Projetos\ntbot\docs\blueprint
python -m http.server 8765
# http://localhost:8765/
